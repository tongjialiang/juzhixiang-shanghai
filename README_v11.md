# 榉之乡上海研修活动报名系统 v11

2026年11月25日成年孤独症家庭未来生活专题研讨交流会报名及运营系统。

## 主要功能

- 手机宣传页、家庭及机构独立报名、报名查询。
- 宽松规则审核、人工审核提醒、研修需求整理。
- 订单、电子票、扫码及名单核销、运营统计。
- 负责人、报名审核、财务、现场核销四种工作权限。
- 家庭基础费用与第四人午餐费可配置；机构标准费用1500元/人，负责人审核核费。

当前支付为模拟接口，尚未接入正式微信支付。生产环境不允许启用模拟支付。

## 本地启动

使用 Node.js 24 和 MySQL。项目采用独立数据库，配置以 `.env.example` 为模板建立 `.env`。数据库账号、登录密码、会话密钥及外部接口密钥由部署人员自行配置，不在仓库提供。

```powershell
npm ci
Copy-Item .env.example .env
# 编辑 .env，填写本机数据库和账号配置。
npm run db:init
npm start
```

`db:init` 需要能够创建项目数据库并授权的本机 MySQL 管理账号，读取 `DB_ROOT_PASSWORD`。默认应用端口3088，MySQL端口3307；可通过 `.env` 调整。已有管理员不会被初始化命令覆盖。

已有本地运行环境可双击“启动本地系统.cmd”。脚本使用 Windows PowerShell；Linux 可直接执行上述 npm 命令。

## 页面入口

- 宣传页：`/shanghai2026/promo/`
- 报名页：`/shanghai2026/apply`
- 查询页：`/shanghai2026/lookup`
- 运营后台：`/shanghai2026/admin`
- 现场核销：`/shanghai2026/checkin`

原根目录入口同样可用。页面采用相对路径。正式域名、HTTPS和微信支付配置需在服务器部署时另行完成。

## 检查

```powershell
npm test
npm run test:full
```

全流程检查会创建独立测试数据库，使用3089端口；后台任务测试使用本机模拟接口，不调用真实提醒或模型服务。测试需要数据库管理权限。

## 分支与本地文件

`main` 保存初始可运行版本，`internal` 用于内部开发。仓库为私有，分支名称不单独控制访问权限。

`.env`、数据库文件、报名数据、测试日志、依赖目录和含本机登录信息的旧说明均不上传。旧说明继续保留在本机。新增工作账号密码需为6–72位字母和数字，且两者均包含。
